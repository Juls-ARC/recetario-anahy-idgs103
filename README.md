# Recetario (versión minimalista)

Recetario hecho con **React + Vite**, con un diseño minimalista: tipografía, espacio en blanco y líneas finas en lugar de tarjetas y colores. Las recetas son estáticas (`src/data/recetas.js`), así que no usa base de datos.

## Recetas
- Chilaquiles rojos
- Pan de elote

## Funcionalidades
- Búsqueda por nombre, categoría o ingrediente
- Ajuste de porciones (las cantidades se recalculan)
- Ingredientes y pasos que se marcan al tocarlos
- Responsive y con modo oscuro automático

## Cómo ejecutar
```bash
npm install
npm run dev
```
